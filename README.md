# ProductRegistrationHub

## Sobre o projeto

O ProductRegistrationHub é um projeto de aprendizado desenvolvido utilizando Clean Architecture.

O principal objetivo é criar uma aplicação backend extensível, capaz de receber diferentes tecnologias e protocolos de comunicação. Atualmente, o projeto utiliza REST e gRPC, mas a ideia é facilitar a adição de novas tecnologias no futuro, como SOAP, GraphQL, RabbitMQ, Kafka e diferentes bancos de dados.

A Clean Architecture ajuda a manter as regras de negócio independentes de frameworks, protocolos de comunicação e bancos de dados. Isso facilita a manutenção, os testes e a adição de novas tecnologias sem a necessidade de alterar o núcleo da aplicação.

## Tecnologias utilizadas

* Java 25
* Spring Boot 4
* REST
* gRPC
* Clean Architecture
